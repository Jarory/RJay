# 阿傑的小屋 — 個人作品集網站

> 我的個人網站，集中展示我的作品、開發經歷與技能。
> 線上瀏覽：https://rjayweb.vercel.app/

## 功能區塊

- **自我介紹**：基本資料與技能專長
- **經歷與證照**：工作經歷、持有證照、歷年競賽紀錄
- **個人作品展示**：串接各專案的線上 Demo 與原始碼
- **遊戲中心**：用原生 JavaScript 手刻的四款小遊戲
  （貪食蛇、踩地雷、打磚塊、貓抓老鼠）
- **響應式設計**：支援桌機與行動裝置瀏覽

## 技術

- HTML / CSS / JavaScript（原生，無框架）
- 部署：Vercel
- 版本控管：Git / GitHub
